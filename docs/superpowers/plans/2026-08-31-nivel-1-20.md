# Criação em qualquer nível (1–20) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Escolher nível N (1–20) no wizard e receber uma ficha `character` correta em N — PV/PM, habilidades de classe do nível certo, cota de poderes acumulada, círculos de magia liberados e pré-requisitos avaliados sobre o personagem final.

**Architecture:** O eixo de nível passa a vir de `T20-DB/data/regras/progressao_classes.json` (`tabela_progressao` por nível, com `automaticos[]` e `escolhas[]`) somado às liberações de círculo de `T20-DB/data/classes/*.json`. `scripts/port-t20db.mjs` emite essa tabela; `src/rules/progressao.ts` vira a única fonte de verdade de nível e todo o resto (writer, passo de poderes, passo de magias) consome dela. Nível no actor é gravado como `system.niveis` no item de classe — o campo que o sistema `tormenta20` realmente usa.

**Tech Stack:** TypeScript strict, Vite lib mode → `dist/module.js`, vitest, Foundry VTT v13 (ApplicationV2), sistema `tormenta20` 1.5.015.

**Spec:** [`../specs/2026-08-31-nivel-1-20-design.md`](../specs/2026-08-31-nivel-1-20-design.md)

```ts
const ESCALONAMENTO = /(?:_con_mais)?_\d+$/;

/** Strips the numeric upgrade suffix so `ataque_especial_8` groups with `ataque_especial`. */
export function baseSlug(slug: string): string {
  return slug.replace(ESCALONAMENTO, "");
}

/**
 * Automatic class abilities a character of this level has, one per family:
 * an upgrade entry (`ataque_especial_8`) replaces its base rather than adding to it.
 */
export function habilidadesAte(classeNome: string, nivel: number): string[] {
  const prog = getClasseProgressao(classeNome);
  if (!prog?.tabela) return [];
  const melhorPorFamilia = new Map<string, { nivel: number; slug: string }>();
  for (const [nvStr, row] of Object.entries(prog.tabela)) {
    const nv = Number(nvStr);
    if (nv > nivel) continue;
    for (const slug of row.automaticos ?? []) {
      const familia = baseSlug(slug);
      const atual = melhorPorFamilia.get(familia);
      if (!atual || nv >= atual.nivel) melhorPorFamilia.set(familia, { nivel: nv, slug });
    }
  }
  return [...melhorPorFamilia.values()]
    .sort((a, b) => a.nivel - b.nivel)
    .map((e) => e.slug);
}

/** Total power picks accumulated from level 1 up to `nivel`. */
export function slotsDePoder(classeNome: string, nivel: number): number {
  const prog = getClasseProgressao(classeNome);
  if (!prog?.tabela) return 0;
  let total = 0;
  for (const [nvStr, row] of Object.entries(prog.tabela)) {
    if (Number(nvStr) <= nivel) total += row.escolhas ?? 0;
  }
  return total;
}

/** Highest spell circle unlocked at `nivel`; 0 when the class does not cast. */
export function circuloMaximo(classeNome: string, nivel: number): number {
  const prog = getClasseProgressao(classeNome);
  if (!prog?.circulos) return 0;
  let max = 0;
  for (const [nvStr, circulo] of Object.entries(prog.circulos)) {
    if (Number(nvStr) <= nivel && circulo > max) max = circulo;
  }
  return max;
}
```
